# CloudSaves

Releases del AppImage de **CloudSaves**, la app que sincroniza los guardados de los juegos con una carpeta en la nube.

Acá solo se publican los binarios: `cloud-saves-linux-amd64.AppImage` y su `SHA256SUMS`. La app los usa para actualizarse sola (Configuración → Buscar actualizaciones). El código no está en este repositorio.
